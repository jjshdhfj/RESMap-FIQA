# Third-party source attribution and release caveats

- **RETFound**: https://github.com/rmaphoh/RETFound and
  https://huggingface.co/YukunZhou/RETFound_mae_natureCFP . The upstream
  RETFound GitHub `LICENSE` is CC BY-NC 4.0; the CFP model card also lists
  CC BY-NC 4.0, and weight download is gated. Include applicable upstream
  license notices and a record of changes when releasing derivatives.
  The full source-file lineage and noncommercial requirements must be checked.
- **GFENet**: https://github.com/liamheng/Annotation-free-Fundus-Image-Enhancement .
  Its upstream model implementation is **not included** in these archives,
  because a clear redistribution permission has not been confirmed.
- **EyeQ / EyePACS**: https://github.com/HzFu/EyeQ . EyeQ documents that
  its original images come from EyePACS and should be acquired separately.
  The EyeQ code license does not automatically cover the source images.

No blanket license is granted for included upstream-derived files or data.
Obtain appropriate permissions before any public redistribution.
